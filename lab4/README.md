# Лабораторная работа: Змейка по сети

## Описание
Цель лабораторной работы — Реализовать многопользовательскую игру "Змейка".
Управляя своей змейкой, нужно поедать "еду" и расти, при этом избежав столкновения с "телом" своей змейки и со змейками, управляемыми другими игроками.

---

## Требования
- Установлен JavaFX SDK, иначе скачать JavaFX SDK

---

## Запуск
- Если запускать в IDEA, то нужно только указать в **Run Configurations** в **VM options**: `<--module-path "C:\javafx-sdk-25\lib" --add-modules=javafx.controls,javafx.fxml>`
  Только указать путь до своей JavaFX SDK
